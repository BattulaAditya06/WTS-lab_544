CSS Styling Methods

This page demonstrates all three types of CSS styling.

Inline CSS

Applied directly on HTML elements using the style="" attribute. Highest specificity.

Embedded CSS

Written inside a <style> tag in the <head> section. Applies to the current page.

External CSS

Linked via <link rel="stylesheet">. Best for reusability and maintainability across pages.
